# LeBonCoin

This project is a mobile app for browsing classified ads, similar to a small ads marketplace. It shows a list of items for sale, lets you view the details of a single ad, and lets you filter the list by category. It was built as a technical test for the company leboncoin in 2019.

The app is written in Swift for iOS and follows an MVVM-C (Model-View-ViewModel + Coordinator) architecture built on a layered framework stack with a strict dependency direction: `LBCNetwork` and `LBCCore` sit at the base with no internal dependencies, `LBCAPI` builds on them to fetch and parse remote JSON, `LBCCoreData` adds persistence on top of `LBCAPI`, and `LBCBridge` exposes the domain models and service facades (`AdvertisementService`, `CategoryService`) that the app consumes as its public surface, with `LBCUIKit` providing reusable UIKit components. The app target (`test_Romain_MULLOT`) talks almost exclusively to `LBCBridge`; Coordinators own navigation, and protocol-fronted ViewModels receive their services via initializer injection for testability. Core Data is the source of truth for the UI — network refreshes write into Core Data, and reads always come back from there, with `ReachabilityService` driving an offline mode that serves cached data when there is no network.
